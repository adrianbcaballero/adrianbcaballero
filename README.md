## Things I've built

### [Aeglero EMR](https://github.com/adrianbcaballero/AegleroEMR)
A multi-tenant EMR built end-to-end for residential addiction and behavioral health programs. SHA-256 hash-chained audit log, per-query tenant isolation, two-axis access control (roles × care teams), TOTP MFA, and 42 CFR Part 2 consent management as first-class records. Companion marketing site at [aeglero.com](https://www.aeglero.com/).

### [Private AI Infrastructure](https://github.com/adrianbcaballero/private-ai-infrastructure)
Self-hosted, security-hardened AI inference environment built from scratch. True L3 VLAN segmentation across three trust zones, with a Raspberry Pi as router-on-a-stick, stateful firewall, and NAT. SNMP monitoring via LibreNMS, Discord-delivered alerts. WireGuard as the only public-facing port. Built to keep all data locally.

### [CAHIMS Anki Deck](https://github.com/adrianbcaballero/cahims-anki)
Spaced-repetition deck for the CAHIMS exam, built and refined while I prepped for it. Mapped to the HIMSS exam blueprint, public for anyone else studying.
