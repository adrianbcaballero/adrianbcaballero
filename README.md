#
  
**[AegleroEMR](https://github.com/adrianbcaballero/AegleroEMR)**  
A multi-tenant EMR built end-to-end for residential addiction and behavioral health
treatment programs: role-based access control, 42 CFR Part 2 consent management, and a
tamper-evident hash-chained audit log, deployed on AWS with Terraform. Companion marketing
site at aeglero.com  
It also ships a continuous compliance engine: it assesses the
running system against all 110 NIST SP 800-171 controls, computes an SPRS score,
auto-generates the System Security Plan and POA&M, and crosswalks every control to HIPAA,
ONC, CMMC Level 2, and 42 CFR Part 2. Evidence is collected straight from the source,
infrastructure, and CI, and an advisory, threat-modeled AI reviewer gives each automated
control a second, independent read. Self-updating dashboard at complaince.aegelro.com
